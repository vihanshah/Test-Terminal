## 🦅 Overview

**Black Swan Terminal** is a high-density, institutional trading workstation and simulation arena. Designed for professional quant traders, it models multi-asset execution, level-2 depth, portfolio risk metrics, and extreme tail-risk stress testing.

---

## ⚡ Core Features

- 📊 **Executive Dashboard**: Real-time portfolio valuation (₹10,84,250), day P&L, multi-asset allocation bar, and active holdings ledger.
- 📈 **Multi-Asset Markets**: Live sync across Equities (NIFTY/SENSEX/Reliance/TCS), Commodities (Gold/Silver), Cryptocurrencies (BTC/ETH), and Commercial REITs.
- ⚡ **Quant Trade Terminal**: Canvas-based interactive candlestick chart with 20 EMA overlay, real-time Level-2 order book with dynamic depth bars, and instant DMA execution slips.
- 👁️ **Watchlist**: Multi-asset asset tracker with 52-week high/low meters, volume analytics, and 1-click trade action.
- 💼 **Portfolio Analytics**: Sharpe Ratio (1.84), Beta (0.78), Max Drawdown (4.2%), and risk distribution charts.
- 📝 **Live Order Queue**: Real-time order status tracking with working order cancellation and modification.
- 📜 **Audit Ledger**: Comprehensive transaction history with DMA execution fees and **1-click CSV Export**.
- 📰 **Institutional Wire**: Live breaking news feed with Bullish/Bearish sentiment badges and daily macroeconomic calendar.
- 🏆 **Arena Leaderboard**: 50-trader competition ranking with Grandmaster/Master/Diamond badges and win rates.
- 🚨 **Black Swan Scenario Simulator**: Real-time tail-risk engine allowing simulation of **Flash Crashes (-18.2%)**, **Oil Embargoes (+25%)**, and **Tech Squeezes (+15%)** with emergency alarm klaxons and live portfolio impact.
- ⚙️ **Terminal Preferences**: Obsidian Dark, Matrix Green, and Amber classic themes, CRT scanline phosphor simulation, and API key management.
- 🛠️ **System Diagnostics**: Live gateway ping monitors (NSE, BSE, MCX, Binance, CME) and diagnostic log streams.

## 🚀 Quick Start

### 1. Clone Repository
\`\`\`bash
git clone https://github.com/vihanshah/Test-Terminal.git
cd Test-Terminal
\`\`\`

### 2. Start Localhost Server
\`\`\`bash
npm start
\`\`\`
*(Automatically starts server and launches your default browser at \`http://localhost:3000\`)*

Or simply open \`index.html\` directly in any modern browser!

---

## ⌨️ Keybindings

- \`Ctrl + K\` or \`Cmd + K\` : Open Command Palette / Symbol Search
- \`Esc\` : Close modals and overlays
